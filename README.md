# ANOUER — التحديثات

هذا المستودع يستعمله زر **«تحديث البرنامج»** داخل ANOUER PRO و ANOUER LITE.

- `latest.json`: رقم آخر نسخة، تاريخها، وما الجديد فيها.
- `anouer-pro.zip` / `anouer-lite.zip`: الملفات التي تغيّرت فقط (تحديث تراكمي)، مع بصمة SHA-256 للتحقق.

التحديث لا يلمس قاعدة البيانات ولا نوع النسخة ولا التفعيلات: الميزات المدفوعة تبقى مقفولة حتى كود التفعيل.
